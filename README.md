# propuesta-mercado-libros
El objetivo es encontrar un factor de valor para incluir en un nuevo producto basado en los servicios que compiten en el mercado de los libros. El DataFrame contiene editoriales, autores y calificaciones de clientes, reseñas de libros. Por ende, se estudiarán, se visualizarán por medio de consultas de SQL para obtener un factor importante para incluir en un nuevo servicio.
